# TopOut Android v1.5 (build 10)

> 과거 릴리스 기록입니다. 현재 릴리스는 [v3.0 versionCode 23](V3_0_BUILD_23_NOTES.md)이며 현재 동작은 [Android README](README.md)를 기준으로 합니다.

## Navigation and recording safety

- 선택 화면의 시스템 뒤로가기는 프리뷰 복귀 동작으로 통일했습니다.
- 카운트다운 또는 녹화 중 시스템 뒤로가기는 Activity를 종료하지 않고 안전한 녹화 종료 경로를 실행합니다.
- 영상 정리와 갤러리 저장 중에는 시스템 뒤로가기를 소비해 CameraX finalization, Media3 export, MediaStore 쓰기가 중간에 취소되지 않도록 했습니다.

## Multi-lens camera zoom

- CameraX 논리 멀티 카메라를 지원하는 기기는 0.5x·1x·망원 구간을 가능한 범위에서 하나의 연속 줌 경로로 사용합니다.
- `0.5x·1x 논리 카메라 + 별도 망원` 혼합형을 감지해 논리 그룹 밖의 망원 경로를 유지하고, 논리 그룹에 이미 포함된 물리 렌즈의 중복 재바인딩은 제거했습니다.
- 분리된 상위 렌즈로 확대할 때는 현재 프리뷰를 한 번 캡처한 뒤 정지 프레임을 핀치 배율에 실시간으로 맞추고, 손을 떼는 시점에 최종 배율로 새 렌즈를 바인딩합니다.
- 확대 도중 이전 경계까지 되돌아오면 전환을 취소하고 기존 라이브 카메라를 즉시 복원합니다. 축소 전환은 즉시 재바인딩한 뒤 준비된 프리뷰로 페이드하는 기존 방식을 유지합니다.
- 렌즈 전환 플래그와 위치 인자 콜백을 고유 ID 기반 상태 머신·타입 이벤트로 통합했습니다. 늦게 도착한 스트림·줌·타임아웃 콜백은 현재 전환 ID와 시도 ID가 일치할 때만 반영합니다.
- 정지 프레임은 전환당 한 번만 캡처하고 배율 상태만 갱신하며, `PreviewView STREAMING`과 목표 줌 적용을 모두 확인한 뒤 제거합니다. 실패 시 이전 렌즈 세션 복구를 시도합니다.
- 30fps·60fps 녹화 모두 센서 타임스탬프 기반 0.5초·0.25초 분석 제한을 사용해 상태별 2fps·4fps 상한을 유지합니다.

## Playback lifecycle

- 촬영 화면은 화면 켜짐을 유지하되 결과 화면에서는 강제를 해제해 사용자의 시스템 자동 잠금 시간을 따릅니다.
- 결과 영상과 실제 MediaStore 저장 영상은 앱이 백그라운드로 이동하면 즉시 일시정지합니다.
- 50ms 간격의 결과 영상 재생 위치 확인은 실제 재생 중에만 실행하고, 일시정지·슬라이더 조작·백그라운드 상태에서는 중단합니다.
- 저장 영상 보기의 앞/뒤 5초 이동, 실시간 슬라이더 탐색, 낮은 컨트롤 스크림 투명도는 그대로 유지합니다.

## Quality and release validation

- ViewModel의 `LifecycleOwner`와 `PreviewView` 참조를 약한 참조로 변경해 화면 재생성 후 이전 Activity가 유지될 위험을 줄였습니다.
- Media3 Transformer 사용 범위에 `UnstableApi` opt-in을 명시해 release lint 오류를 해소했습니다.
- Android JVM 단위 테스트 71개와 `lintRelease`를 통과했습니다. 논리 멀티 카메라·혼합형 망원·완전 분리형 경로와 핀치 전환·복귀 동작을 회귀 테스트에 포함했습니다.
