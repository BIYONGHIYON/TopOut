# TopOut Android v1.7 (build 15)

## Nine-language interface

- 영어, 한국어, 일본어, 중국어 간체·번체, 프랑스어, 독일어, 스페인어, 포르투갈어로 앱 내 문구를 현지화했습니다.
- 기본값은 기기 언어에 맞추는 `자동`이며 설정에서 앱 언어를 직접 선택할 수 있습니다.
- Android 앱별 언어 설정과 동기화하고, 지원하지 않는 언어는 영어로 표시합니다.
- 양 플랫폼의 공통 JSON 문구 카탈로그를 사용해 기능 문구와 오류·권한·접근성 설명을 함께 관리합니다.

## Start detection hardening

- 시작선과 종료선은 선택 영상 높이를 기준으로 매트 경계보다 각각 `6%`, `4%` 위에 둡니다.
- 어깨와 골반이 각각 `1개` 이상 중앙 `80%`에서 확인될 때는 팔다리의 가장자리 접촉과 무관하게 기존 시작 판정을 유지합니다.
- 어깨 또는 골반 그룹이 없거나 몸통 관절 하나라도 좌우 `10%`에 있으면, 발목 `1개`를 포함한 무릎·발목 합계 `3개` 이상일 때만 새 등반 시작 후보로 사용합니다.
- 보수적 하체 조건은 시작 판정에만 적용하며 활성 등반의 추적·종료 기준은 유지합니다.
- 최초 Pose ROI는 선택된 움직임 영역의 `1.5배`, 추적 ROI는 신뢰 관절 영역의 `1.5배` 정사각형으로 구성합니다.

## Stability and efficiency

- Motion 변화율·셀 점수와 MoveNet 관절 경계를 단일 순회로 정리하고 같은 프레임의 계산 결과를 재사용합니다.
- 중지·재설정 이전에 시작된 추론 결과는 상태 세대가 다르면 폐기해 다음 촬영의 luma 기준·ROI·구간 이벤트를 오염시키지 않습니다.
- 늦은 MobileSAM 결과가 해제한 임베딩을 다시 남기지 않게 하고, ONNX 세션 해제는 진행 중인 네이티브 호출 뒤에서 직렬화합니다.
- 카운트다운 취소·백그라운드 전환·카메라 세션 교체 뒤 늦게 완료된 줌 콜백이 녹화를 시작하지 못하도록 요청 세대를 검증합니다.
- 일부 OEM의 줌 future가 실패하거나 응답하지 않으면 최대 1.5초 뒤 현재 세션으로 한 번만 시작해 `STARTING` 무한 대기를 방지합니다.
- Start 이벤트 전에 취소된 Recorder의 콜백과 임시 파일을 폐기하고 UI를 촬영 대기 상태로 복구합니다.
