# iOS UI/UX 대응표

이 문서는 Android 화면을 수정할 때 iOS 버전과의 시각적 차이를 확인하기 위한 기준입니다.

## 카메라 화면

| 항목 | Android 구현 |
|---|---|
| 배경 | 순수 검정 `#000000` |
| 상단 안내 | 흰색 14sp SemiBold, 중앙 정렬, 최대 2줄 |
| 준비 완료 | 180 × 54dp 파란 캡슐(자동 구간 탐지 ON) |
| 녹화 시작 | 180 × 52dp 빨간 캡슐, 문구 없이 녹화 아이콘(흰 원 테두리 + 빨간 원). 자동 구간 탐지 OFF일 때 준비 완료 자리, 보정 화면에서는 다시 촬영 오른쪽 |
| 설정 | 44dp 원형 회색 버튼 |
| 녹화 종료 | 210 × 54dp 빨간 캡슐 |
| 줌 표시 | 왼쪽 하단 Monospace 15sp |
| 도움말 | 반투명 검정 캡슐, 흰색 13sp |

## 경계선 보정과 탑홀드 선택

- `준비 완료` 분석용 정지 이미지는 표시하지 않고 iOS와 동일하게 라이브 카메라 프리뷰 위에서 경계선을 보정합니다.
- 매트 경계는 검정 under-stroke 위의 파란 선과 드래그 점으로 표시하며, Swift처럼 x는 고정하고 y만 보정합니다. 실시간 영상이 보이는 녹화 중에도 같은 방식으로 보정합니다.
- 보정 화면 하단에는 `다시 촬영`과 빨간 녹화 시작 버튼을 동일한 너비로 배치합니다.
- Ready 이후 렌즈·줌·회전 기준을 고정합니다.
- 탑홀드는 녹화 전에 고르지 않고 결과 화면에서 멈춘 프레임을 탭해 고릅니다. 두 손가락으로 1배~5배 확대한 뒤 탭할 수 있고, 외곽선은 굵은 빨간 선 위에 얇은 흰 선을 중첩합니다.

## 결과 화면

| 항목 | Android 구현 |
|---|---|
| 영상 표시 | 검정 배경 + `RESIZE_MODE_FIT` |
| 슬라이더 | 회색 전체 트랙, 파란 선택 트랙, 흰 핸들·재생 헤드 |
| 미세 조정 | 35dp/s 이하가 0.14초 유지되면 진입 |
| 햅틱 | 미세 조정 진입 순간 1회 |
| 스냅 | 0.1초 |
| 버튼 높이 | 42dp |
| 버튼 간격 | 8dp |
| 좌우 여백 | 18dp |
| 재생 종료 | 선택 구간 끝에서 멈춤 |
| 닫기 | 도움말 활성화 시 삭제 확인창 |
| 저장 확인 | MediaStore에 저장된 실제 content URI를 다시 열어 앱 안에서 재생 |
| 저장 영상 이동 | 앞/뒤 5초, 슬라이더 이동 중 화면 즉시 seek |
| 저장 영상 컨트롤 | Media3 스크림을 낮춘 반투명 UI, Fold 가로 화면에서도 슬라이더와 복귀 버튼 분리 |

## 설정 화면

- iOS 설정 화면처럼 밝은 `#F2F2F7` 배경과 흰색 카드 섹션을 사용합니다.
- 상단에 `닫기 / 설정 / 저장`을 배치합니다.
- Segment Control은 회색 바탕과 흰색 선택 셀로 구성합니다.
- 지원하지 않는 해상도·FPS는 회색 비활성화합니다.
- 스위치 활성 색상은 iOS system green과 유사한 `#34C759`입니다.

## Z Flip3 시각 검수 순서

1. 펼친 세로 모드에서 9:16 프레임과 하단 버튼 중앙 정렬 확인
2. 가로 회전 후 16:9 프레임과 설정 비율 제목 확인
3. 접었다 펼친 뒤 매트 선·설정 상태 유지 확인
4. 시스템 글자 크기를 기본값으로 두고 iOS 스크린샷과 간격 비교
5. 카메라 컷아웃과 내비게이션 바가 버튼을 가리지 않는지 확인
