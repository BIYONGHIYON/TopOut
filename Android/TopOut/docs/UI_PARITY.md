# iOS UI/UX 대응표

이 문서는 Android 화면을 수정할 때 iOS 버전과의 시각적 차이를 확인하기 위한 기준입니다.

## 카메라 화면

| 항목 | Android 구현 |
|---|---|
| 배경 | 순수 검정 `#000000` |
| 상단 안내 | 흰색 14sp SemiBold, 중앙 정렬, 최대 2줄 |
| 준비 완료 | 180 × 54dp 파란 캡슐 |
| 설정 | 44dp 원형 회색 버튼 |
| 녹화 종료 | 210 × 54dp 빨간 캡슐 |
| 줌 표시 | 왼쪽 하단 Monospace 15sp |
| 도움말 | 반투명 검정 캡슐, 흰색 13sp |

## 탑홀드 선택 화면

- 카메라 프리뷰를 정지 이미지로 덮어 iOS와 동일한 선택 흐름을 유지합니다.
- 이미지 확대 범위는 1배~5배입니다.
- 매트 경계는 검정 under-stroke 위의 파란 선과 드래그 점으로 표시하며, Swift처럼 x는 고정하고 y만 보정합니다.
- 탑홀드 외곽선은 굵은 빨간 선 위에 얇은 흰 선을 중첩합니다.
- 하단에는 `다시 촬영`과 `녹화 시작` 버튼을 동일한 너비로 배치합니다.

## 결과 화면

| 항목 | Android 구현 |
|---|---|
| 영상 표시 | 검정 배경 + `RESIZE_MODE_FIT` |
| 슬라이더 | 회색 전체 트랙, 파란 선택 트랙, 흰 핸들·재생 헤드 |
| 미세 조정 | 35dp/s 이하가 0.14초 유지되면 진입 |
| 햅틱 | 미세 조정 진입 순간 1회 |
| 스냅 | 0.1초 |
| 버튼 높이 | 42dp |
| 버튼 간격 | 8dp |
| 좌우 여백 | 18dp |
| 재생 종료 | 선택 구간 끝에서 멈춤 |
| 닫기/재촬영 | 도움말 활성화 시 삭제 확인창 |

## 설정 화면

- iOS 설정 화면처럼 밝은 `#F2F2F7` 배경과 흰색 카드 섹션을 사용합니다.
- 상단에 `닫기 / 설정 / 저장`을 배치합니다.
- Segment Control은 회색 바탕과 흰색 선택 셀로 구성합니다.
- 지원하지 않는 해상도·FPS는 회색 비활성화합니다.
- 스위치 활성 색상은 iOS system green과 유사한 `#34C759`입니다.

## Z Flip3 시각 검수 순서

1. 펼친 세로 모드에서 9:16 프레임과 하단 버튼 중앙 정렬 확인
2. 가로 회전 후 16:9 프레임과 설정 비율 제목 확인
3. 접었다 펼친 뒤 선택한 탑홀드·매트 선·설정 상태 유지 확인
4. 시스템 글자 크기를 기본값으로 두고 iOS 스크린샷과 간격 비교
5. 카메라 컷아웃과 내비게이션 바가 버튼을 가리지 않는지 확인
