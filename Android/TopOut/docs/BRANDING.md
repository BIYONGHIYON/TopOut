# Android branding assets

- `LaunchLight.png` / `LaunchDark.png`: Compose brand launch screen selected by system light/dark mode.
- `Default-logo.png`: default launcher icon source.
- `Dark-logo.png`: night-mode launcher icon source.
- `Tinted-logo.png`: system splash symbol and Android themed-icon monochrome source.
- Brand launch screen duration: `MainActivity.BRAND_LAUNCH_DURATION_MILLIS` (currently 1,000 ms).

Android shows its native SplashScreen first, followed briefly by the supplied full-screen launch artwork.
