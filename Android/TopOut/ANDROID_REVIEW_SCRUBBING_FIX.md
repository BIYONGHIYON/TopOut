# Android 결과 화면 슬라이더 응답 개선

## 변경 내용

- AndroidX Media3의 scrubbing mode를 드래그 중에만 활성화합니다.
- 드래그 이벤트가 화면 주사율보다 빠르게 들어와도 오래된 seek 요청이 쌓이지 않도록 최신 위치만 최대 16ms 간격으로 전달합니다.
- 슬라이더를 놓으면 scrubbing mode를 끄고 마지막 위치를 `SeekParameters.EXACT`로 한 번 더 맞춥니다.
- 재생 구간 선택, 저장, 포즈 감지 및 원본 구간 정리 로직은 변경하지 않았습니다.

## 동작

1. 슬라이더 터치 시작: 재생 일시정지 및 scrubbing mode 활성화
2. 드래그 중: 최신 요청 위치로 빠르게 화면 갱신
3. 터치 종료: 마지막 요청 위치를 정확한 프레임으로 보정

Media3 버전은 기존 프로젝트의 1.10.1을 유지합니다.
