# Raw detection → cleanup → padding

Android 자동 구간 처리는 다음 순서로 동작합니다.

1. 녹화 중에는 YOLO11n-Pose가 판정한 원본 시작·종료 시각만 저장합니다.
2. 녹화가 끝난 뒤 원본 길이가 2초 미만인 구간을 찾습니다.
3. 짧은 구간은 원본 시간 기준으로 이전·다음 구간과의 간격을 계산합니다.
4. 간격이 3초 이내인 이웃이 있으면 더 가까운 쪽과 병합합니다. 양쪽 간격이 같으면 이전 구간과 병합합니다.
5. 3초 이내 이웃이 없으면 해당 짧은 구간을 폐기합니다.
6. 병합 결과가 여전히 2초 미만이면 같은 검사를 반복합니다.
7. 모든 병합·폐기가 끝난 뒤 남은 각 원본 구간에 앞뒤 3초를 추가합니다.
8. 패딩은 영상 시작 0초와 실제 영상 종료 시각을 넘지 않도록 제한합니다.
9. 정상 구간끼리는 최종 패딩 영역이 겹치거나 맞닿아도 각각 유지합니다.
10. 구간 개수 제한은 없습니다.

예시:

- 원본 A: 10~15초
- 원본 B: 18~19초 (1초, 짧은 구간)
- 원본 간격: 3초

정리 결과는 원본 10~19초로 병합되고, 마지막에 패딩을 붙여 7~22초가 됩니다.
