# Android 결과 타임라인 — 선택된 구간 확대 슬라이더

## UI

- 기존 결과 타임라인 바로 위에 `선택된 구간 확대` 배율 슬라이더를 배치했습니다.
- 왼쪽 끝은 `1.0×` 전체 보기이며, 오른쪽으로 이동할수록 현재 선택된 시작~종료 구간의 중앙을 기준으로 확대됩니다.
- 핀치 제스처는 결과 타임라인에서 제거했습니다.

## 확대 제한

- 선택된 시작점과 종료점이 확대 화면 밖으로 나가지 않도록 최대 배율을 구간 길이에 따라 동적으로 제한합니다.
- 최대 확대 시에도 선택 구간 양쪽에 `max(0.35초, 선택 구간 길이의 16%)` 여백이 남습니다.
- 기존 전역 제한인 최대 12배, 최소 표시 범위 2초도 함께 유지합니다.
- 영상 시작·끝과 가까운 구간은 영상 범위 안에서 최대한 중앙에 배치하며 두 핸들은 항상 트랙 안에 남습니다.

## 확대감 표현

- 원래 트림 슬라이더에 시간 눈금을 추가했습니다.
- 배율이 커질수록 주요 눈금 사이의 픽셀 간격이 벌어집니다.
- 간격이 충분히 넓어지면 2·5·10단계 보조 눈금이 나타나 더 세밀하게 조정되는 느낌을 줍니다.

## 유지 항목

- Media3 Scrubbing Mode 기반 즉시 프레임 탐색
- 절대 영상 시각 기준 시작점·종료점·재생 헤드
- 원본 구간 2초 미만 처리, 원본 간격 3초 병합, 정리 후 3초 패딩
- 감지 구간 개수 무제한
- ML Kit Accurate Pose Detection
