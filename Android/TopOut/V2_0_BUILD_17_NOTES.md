# TopOut Android v2.0 (versionCode 17)

## 릴리스 기준

- Version name: `2.0`
- Google Play versionCode: `17`

## 주요 변경 사항

- 한국어 촬영·선택·결과 안내를 간략화 이전의 자세한 문구로 복원
- 9개 언어에서 벽과 매트 사이의 경계, 파란 점 조작, 시작~완등 구간처럼 사용자가 확인할 대상을 구체적으로 안내
- 상단 안내·하단 Tip의 한 줄 자동 축소 유지
- 탑홀드 분석을 매트 분석과 별도로 5초 제한하고, 시간 초과·모델 오류·빈 결과에는 탭 위치의 기본 원형 마스크 사용
- 늦게 끝난 ONNX 분석 결과가 현재 선택을 덮어쓰지 않도록 요청 상태 보호

## 릴리스 전 확인

- 한국어 상단 안내와 Tip이 한 줄 자동 축소 안에서 전체 의미를 표시하는지 확인
- 다른 8개 언어도 구체화한 안내가 작은 화면에서 잘리거나 두 줄로 바뀌지 않는지 확인
- 탑홀드 분석 제한 시간 이후 기본 원이 표시되고 녹화를 이어갈 수 있는지 확인
- Google Play 업로드 전 versionName `2.0`, versionCode `17` 확인
