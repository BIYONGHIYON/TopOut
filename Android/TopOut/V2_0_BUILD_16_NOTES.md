# TopOut Android v2.0 (versionCode 16)

## 릴리스 기준

- Version name: `2.0`
- Google Play versionCode: `16`

Android의 `versionCode`는 Google Play에 배포한 이전 값보다 항상 커야 하므로 v1.7의 `15` 다음 값인 `16`을 사용합니다. 사용자에게 표시되는 앱 버전은 `2.0`입니다.

## 주요 변경 사항

- 영어, 한국어, 일본어, 중국어 간체, 중국어 번체, 프랑스어, 독일어, 스페인어, 포르투갈어 UI 지원
- 기본 `자동` 언어 선택과 설정 내 수동 언어 변경 추가
- Android 앱별 언어 설정과 시스템 언어 우선순위 연동
- 카메라·녹화·결과 편집·설정·오류·접근성·개인정보처리방침 문구 현지화
- 지원하지 않는 언어는 영어로 안전하게 대체
- 언어 선택 즉시 설정 내부를 미리보기하고 `저장` 시에만 선택값을 확정
- 촬영·결과 버튼의 두 줄 정렬·자동 축소와 설정 스위치 폭 보존으로 긴 번역 레이아웃 보강
- 촬영 Tip 배너가 가로폭에 맞춰 자동으로 작아지도록 조정해 프랑스어·독일어 등 긴 안내 문구를 한 줄로 표시
- 촬영·선택·결과 화면의 긴 상단 상태 문구를 최대 두 줄로 표시해 작은 화면에서 잘리는 문제 방지
- 언어 선택값은 앱 내부에만 저장하며 영상·분석 데이터 처리 방식은 변경하지 않음

## 릴리스 전 확인

- 각 언어에서 긴 설정·경고 문구의 줄바꿈과 가로·세로 UI 확인
- 시스템 앱별 언어와 TopOut 설정 언어 변경 시 현재 화면 갱신 확인
- Google Play 업로드 전 versionName `2.0`, versionCode `16` 확인
