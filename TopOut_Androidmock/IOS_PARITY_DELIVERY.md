# TopOut Android Mock 전달 메모

이 폴더는 실제 카메라 대신 `app/src/main/assets/mock/test.MOV`를 반복 입력하는 테스트 전용 앱입니다.

이번 실험본은 iOS와의 포즈 분석 동등성보다 사람 위치 기반 자동 감지 로직을 검증하는 데 목적이 있습니다.

- 4fps 전체 프레임 변화 감지
- 변화 발생 후 2fps 사람 객체 탐지
- 1초 동안 사람이 없으면 변화 감지 상태로 복귀
- 사람 바운딩 박스와 매트 경계로 시작·종료 판단
- Mock 영상과 결과 재생 음소거

프로덕션 Android 앱과 iOS 앱은 변경하지 않습니다.
