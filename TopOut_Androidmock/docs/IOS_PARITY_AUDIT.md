# Mock 사람 탐지 실험 안내

이 프로젝트는 일반 TopOut 앱과의 iOS/Android 동등성 검증용 배포본이 아니라, `test.MOV` 반복 입력에서 새로운 자동 감지 로직을 확인하기 위한 Mock 전용 실험본입니다.

## Mock 전용 변경 사항

- 전체 화면의 연속 프레임 차이를 4fps로 비교
- 변화가 감지되면 EfficientDet-Lite2 사람 객체 탐지를 2fps로 실행
- 1초 동안 사람이 없으면 저비용 프레임 변화 감지로 복귀
- 사람이 발견되면 바운딩 박스의 위치와 매트선을 사용해 시작·종료 판정
- Pose Landmarker 및 관절 판정은 Mock 빌드에서 제거

일반 앱은 이 문서의 변경 대상이 아닙니다.
