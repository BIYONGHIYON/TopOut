# TopOut 개인정보 처리방침 배포 전 확인

개인정보 처리방침 URL: https://topoutprivacy.vercel.app/

## 반드시 확인할 항목

1. 개인정보 처리방침에 적힌 개발자/운영자 이름을 Google Play 개발자 이름과 동일하게 표시합니다.
2. 카메라 영상 프레임과 포즈 랜드마크가 기기 내부에서만 분석되고 외부 서버로 전송되지 않는다고 명시합니다.
3. MediaPipe 및 ONNX Runtime 등 포함된 오픈소스 라이브러리는 기기 내 연산에만 사용되며 사용자 데이터를 해당 제공자에게 전송하지 않는다고 명시합니다.
4. Android에서는 기존 사진·영상을 읽지 않고 새로 촬영한 영상을 미디어 저장소에 저장한다는 실제 동작을 명시합니다.
5. 촬영 영상과 음성의 보관 기간은 사용자가 직접 삭제할 때까지이며, 앱 삭제만으로 사진 앱에 저장된 영상이 자동 삭제되지 않을 수 있음을 명시합니다.
6. 문의 이메일이 실제로 확인 가능한 주소인지 확인합니다.

## 앱 설정 반영

설정 > 앱 정보에 다음 항목을 추가했습니다.

- 개인정보 처리방침: 외부 브라우저로 위 URL 열기
- 오픈소스 라이선스
- 앱 버전
- 카메라·마이크 사용 및 외부 전송 없음 안내
