# TopOut Android Mock 테스트 가이드

이 버전은 카메라와 Pose 모델을 사용하지 않고, 번들된 `test.MOV`의 프레임을 사람 객체 탐지 입력으로 사용합니다.

## 사용 순서

1. `app/src/main/assets/mock/test.MOV`에 테스트 영상을 둡니다.
2. Android Studio에서 Gradle Sync 후 앱을 실행합니다.
3. 영상이 자동 재생되면 **준비 완료**를 누릅니다.
4. 매트 경계와 필요한 경우 탑홀드를 확인합니다.
5. 녹화를 시작하면 영상이 0초부터 무한 반복됩니다.
6. 원하는 시간 뒤 정지 버튼을 눌러 결과 화면과 자동 감지 구간을 확인합니다.

## 내부 처리

```text
4fps 연속 프레임 변화 감지
→ 변화 발생
→ EfficientDet-Lite2 person 탐지 2fps
→ 1초 동안 person 없음: 변화 감지로 복귀
→ person 발견: 바운딩 박스 추적
→ 현재 박스 bottom이 매트 기준선 위로 이동: 즉시 시작
→ 현재 박스 bottom이 다시 아래로 이동: 즉시 종료
```

- 시작·종료 클립에는 기존처럼 앞뒤 3초 여유가 적용됩니다.
- 최고점 기준은 사람 박스의 `top`이 가장 높았던 시점을 사용합니다.
- 탑홀드 기준은 사람 박스 상단 중앙점이 탑홀드 영역에 가장 가까웠던 시점을 사용합니다.
- 영상 재생과 생성되는 Mock 결과 파일은 무음입니다.
- 테스트 영상의 화면 비율이 설정 비율과 다르면 중앙 크롭됩니다.


## 화면 비율과 변화 감지

Mock 입력 프레임은 설정한 9:16, 4:5, 3:4, 1:1 비율(가로 모드에서는 역비율)로 중앙 크롭된 뒤 변화 감지와 사람 탐지에 전달됩니다. 따라서 화면에 보이는 촬영 영역과 분석 영역이 같습니다.

사람을 한 번 찾은 뒤에는 전체 화면 변화 여부와 관계없이 2fps 사람 탐지를 계속합니다. 등반자가 벽에서 가만히 있거나 천천히 움직여도 추적은 유지되며, 5초 동안 사람을 연속으로 놓친 경우에만 종료 처리합니다.

## 객체 탐지 실행 장치
MediaPipe GPU delegate의 제조사·GPU 드라이버별 네이티브 크래시를 피하기 위해
모든 Android 기기에서 EfficientDet-Lite2 객체 탐지를 CPU 2fps로 실행합니다.
