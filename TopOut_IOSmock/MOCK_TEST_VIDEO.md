# TopOut test.mov 목업 입력

이 프로젝트는 화면·녹화·분석에는 `TopOut/test.mov`를 카메라 입력처럼 사용합니다.

- `test.mov`가 준비되면 프리뷰에서 자동으로 무한 반복 재생합니다.
- 준비 완료 캡처, 녹화, 모션 탐지, 결과 화면은 모두 같은 목업 프레임을 사용합니다.
- 실제 후면 카메라는 권한이 허용된 기기에서 별도의 `AVCaptureSession`으로 함께 실행됩니다.
- 실제 카메라 영상은 화면, 녹화, 분석에 표시되거나 사용되지 않습니다.
- 실제 테스트 영상으로 바꾸려면 `TopOut/test.mov`를 같은 이름의 MOV 파일로 교체하세요.
- `test.MOV`처럼 확장자가 대문자여도 인식합니다.
