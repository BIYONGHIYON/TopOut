# TopOut iOS v1.6 (build 12)

> 과거 릴리스 기록입니다. 현재 릴리스는 [v3.0 build 23](V3_0_BUILD_23_NOTES.md)이며 현재 동작은 [iOS README](README.md)를 기준으로 합니다.

## Mat analysis recovery

- 메모리 제약 기기 사용자 피드백을 반영해 매트 경계 분석 대기를 5초로 제한했습니다.
- 제한 시간 안에 Core ML 분석이 끝나지 않으면 y=`75%` 기본 경계로 전환하고 사용자가 직접 보정해 촬영을 계속할 수 있습니다.
- 분석이 먼저 끝나거나 선택 화면을 벗어나면 예약된 watchdog을 취소합니다. 늦게 도착한 결과는 현재 선택을 덮어쓰지 않습니다.

## Review and copy parity

- 시작점 수정 후에는 새 시작점부터, 끝점 수정 후에는 새 끝점의 3초 전부터 자동 재생합니다.
- 선택 구간 확대 배율은 작은 손잡이를 정확히 누르지 않아도 슬라이더 트랙을 탭하거나 바로 드래그해 조절할 수 있습니다.
- 선택 구간 확대 배율은 별도의 진동 없이 트랙 탭과 드래그에 바로 반응하도록 통일했습니다.
- 다시 촬영 확인창의 긴 경고 본문만 13pt 기준으로 줄이고 접근성 글자 크기 확대는 유지했습니다.
- 트림 종료 콜백을 하나로 합쳐 타임라인 재정렬과 미리보기 재생 순서를 명확히 했습니다.
- 매트 보정, 안전한 녹화 종료와 저장 진행 문구를 Android와 통일했습니다.

## Low-memory and long-recording stability

- Ready 분석과 탑홀드 선택의 MobileSAM 임베딩 수명을 분리하고, 녹화 진입·백그라운드·메모리 경고에서 모델 참조를 안전하게 해제합니다.
- 프롬프트별 Core ML 임시 결과를 즉시 정리해 메모리 제약 기기의 분석 peak를 낮췄습니다.
- 4K·60fps 입력이 writer보다 빨라도 전체 해상도 프레임이 비동기 큐에 무한히 쌓이지 않도록 녹화 역압력을 적용했습니다.
- 비활성·결과·내보내기 상태에서 늦은 카메라 또는 오디오 복구가 세션을 다시 시작하지 않도록 차단했습니다.
- 결과 화면에서 바로 다시 촬영할 때 MobileSAM 재로딩이 녹화 시작과 겹치지 않도록 하고, 백그라운드에서 돌아온 선택 화면은 카메라와 모델 준비를 다시 시작하도록 정리했습니다.
- 자동 종료가 저장 가능한 프레임 없이 끝난 시점에 앱이 이미 활성 상태여도 카메라 프리뷰가 멈춘 채 남지 않도록 복구했습니다.

## Validation

- Xcode 26.5 iOS Simulator SDK에서 전체 Swift 소스와 MobileSAM Core ML 인터페이스를 포함한 Debug 빌드를 통과했습니다.
- Archive·IPA는 생성하지 않았으며 메모리 제약 기기의 최종 동작은 실기기 또는 TestFlight에서 확인합니다.
