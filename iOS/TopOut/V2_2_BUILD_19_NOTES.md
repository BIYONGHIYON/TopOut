# TopOut iOS v2.2 (build 19)

## 릴리스 기준

- Marketing Version: `2.2`
- Current Project Version: `19`

## 주요 변경 사항

- 자동 구간 탐지의 매트 경계 준비 또는 탑홀드 선택 완료 후 1분 동안 녹화 시작을 누르지 않으면 기존 3초 카운트다운 자동 시작
- 1분 대기 중에는 기존 선택 안내를 유지하고 자동 시작 직전 5초 동안만 안내 문구 표시
- 재선택·재촬영·백그라운드 전환 시 자동 시작 예약을 취소하고 중복 타이머 방지
- 분석 timeout 이후 늦은 결과가 새 선택 상태와 섞이지 않도록 요청별 취소와 상태 검증 강화
- 탑홀드 마스크 렌더링과 영상 내보내기·사진 보관함 저장의 리소스 소유 및 정리 경로 개선
- 카메라·분석·녹화·저장·리뷰의 비동기 완료와 화면 생명주기 처리 정돈
- 결과 화면의 선택 구간 확대 상한을 30배로 확장
- 조각난 매트 마스크의 상단도 강건 직선으로 결합하고 위·아래 이상치를 제외한 화면 너비 60% 이상의 지지선만 경계 후보로 사용

## 릴리스 전 확인

- 자동 탐지만 사용, 탑홀드 마스킹만 사용, 두 기능을 함께 사용하는 각 조합에서 1분 자동 시작 확인
- 경계 보정값과 마지막 탑홀드 선택이 자동 시작 녹화에 그대로 적용되는지 확인
- 재선택·재촬영·백그라운드 전환 시 이전 타이머와 늦은 분석 결과가 동작하지 않는지 확인
- App Store 업로드 전 Marketing Version `2.2`, Current Project Version `19` 확인
