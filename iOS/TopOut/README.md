# TopOut iOS v1.6 (build 14)

> 등반 시작부터 완등 순간까지, 자동으로 찾아주는 클라이밍 촬영 앱

TopOut은 실내 클라이머를 위한 스마트 등반 영상 녹화 앱입니다.

TopOut이 사용자의 움직임을 분석해 등반 시작부터 완등 순간까지 필요한 구간을 자동으로 찾아줍니다. 한 번의 영상에 여러 번의 등반이 담겨 있어도 각각의 시도를 구분합니다.

촬영이 끝나면 자동으로 선택된 구간을 확인하고, 시작점과 종료점을 원하는 위치로 세밀하게 조정한 뒤 필요한 장면만 사진 앱에 저장할 수 있습니다.

**출시 상태: 출시 완료**

[App Store에서 TopOut 보기](https://apps.apple.com/kr/app/topout/id6790163178)

## 주요 기능

- 매트 경계 자동 탐지 및 직접 보정
- 움직임을 분석해 등반 시작과 종료 시점 감지
- 한 번의 촬영에서 여러 등반 시도 자동 구분
- 자동으로 찾은 구간을 간편하게 미세 조정
- 원하는 등반 장면만 사진 앱에 저장
- 촬영 중단과 저장공간 부족 상황에 안전하게 대응

모든 영상 분석은 사용자의 기기 안에서 이루어집니다. 긴 영상을 다시 돌려보며 등반 장면을 찾고 편집하는 시간을 줄이고, 클라이밍에 더 집중할 수 있도록 설계했습니다.

## 현재 릴리스

- Bundle ID: `com.topout.cam`
- Deployment Target: iOS 16.0
- Marketing / Current Project Version: `1.6` / `14`
- UI: Swift, UIKit
- Camera / media: AVFoundation, AVAssetWriter, AVPlayer, PhotoKit
- AI: MobileSAM Core ML, Apple Vision Human Body Pose

## 촬영 준비와 매트 경계

- 앱 시작과 카메라 권한·프리뷰 준비는 MobileSAM 로딩을 기다리지 않습니다. 실제 카메라 프레임이 안정된 뒤 모델을 백그라운드에서 준비하고, CPU와 Neural Engine만 사용해 구형 iPhone의 시작 시 GPU·메모리 압박을 줄입니다.
- 실제 비디오 프레임 6장이 도착하기 전에는 `준비 완료` 버튼을 활성화하지 않습니다.
- Ready 이후 최소 4개의 새 프레임과 0.2초를 기다리고, 노출·초점·화이트밸런스가 2프레임 연속 안정된 프레임을 우선 사용합니다. 0.9초가 지나면 최신 프레임으로 진행하며 전체 요청 제한은 1.8초입니다.
- 자동 매트 분석 프레임은 MobileSAM 입력에만 사용하고, 매트 보정과 탑홀드 선택은 라이브 프리뷰 위에서 진행합니다.
- MobileSAM은 y=`70%`, `80%`, `90%`, `95%` 프롬프트를 사용하며 후보가 없으면 y=`75%` 기본선을 제안합니다.
- Core ML 매트 분석이 5초 안에 끝나지 않으면 대기를 끝내고 y=`75%` 기본선을 표시해 사용자가 직접 보정할 수 있습니다. 이후 도착한 분석 결과는 현재 선택 상태를 덮어쓰지 않습니다.
- Ready 이후 카메라 방향·렌즈·줌을 고정합니다. 탑홀드는 탭할 때마다 새 비디오 프레임으로 계산합니다.
- 전화나 다른 앱의 오디오 점유가 끝나면 다음 녹화를 위해 마이크 입력·출력을 카메라 세션에 다시 연결합니다.
- 세로 화면의 준비·설정·줌·녹화 컨트롤은 홈 버튼과 홈 인디케이터를 침범하지 않도록 하단 안전 영역 안에 배치합니다.

## 자동 구간 탐지

- Motion: 160px luma, 현재 프레임과 직전 분석 프레임 비교, 기본 2fps
- 초기 탐색: 편집된 매트선 위 선택 영상 높이 40% 영역
- Pose: `VNDetectHumanBodyPoseRequest`, 활성 촬영 영역의 긴 변 최대 384px
- 8열 Motion 격자의 변화 영역과 가장 잘 맞는 Vision observation 한 명을 최초 대상으로 선택
- 추적 중에는 직전 대상의 관절 경계·중심과 가장 자연스럽게 이어지는 한 명만 유지
- 선택된 사람의 confidence `0.25` 이상 비얼굴 관절만 시작·종료·완등 판단에 사용
- 시작선: x별 매트선보다 선택 영상 높이 `6%` 위
- 종료선: x별 매트선보다 선택 영상 높이 `4%` 위
- 시작 전·종료 후·Pose 유실 복구: 4fps
- 활성 등반 Pose 유실 허용: 최대 6초
- 정상 종료 후 Pose 2회 연속 미검출: 초기 Motion 탐색으로 복귀

녹화 설정의 30fps·60fps는 카메라와 인코더 프레임률입니다. 분석기는 `CMSampleBuffer`의 presentation timestamp를 기준으로 0.5초 또는 0.25초가 지나기 전 프레임을 건너뛰므로 두 설정 모두 상태별 분석 상한은 2fps·4fps로 같습니다. 분석 중에는 최신 대기 프레임 한 장만 유지하므로 처리 시간이 길어지면 큐를 쌓지 않고 실제 분석 빈도가 이 상한보다 낮아질 수 있습니다.

iOS는 Vision 추론을 사람별로 반복하지 않습니다. 한 번의 다중 observation 결과에서 초기 Motion 격자 겹침과 거리, 이후 프레임의 대상 연속성을 비교하므로 추가 모델 추론 없이 주변 인물의 관절이 주 등반자의 판정에 섞이는 것을 방지합니다. 직전 대상과 겹치지 않고 정규화된 촬영 영역에서 중심 거리가 `0.40`보다 먼 인물은 즉시 대체하지 않습니다. Android의 anatomical group gate는 적용하지 않으며, 기존 Pose 유실 정책을 거쳐 초기 Motion 탐색으로 돌아왔을 때만 새 대상을 선택합니다.

### 프로토타입에서 현재 구조까지

iOS는 TopOut의 최초 제품 기준선입니다. 초기에는 화면 하단 색상·밝기·균일도를 조합한 규칙 기반 MatDetector와 단순 Motion 시작·종료 판정을 사용했습니다. 필드 영상에서 그림자, 큰 볼륨의 외곽선, 카메라 흔들림, 노출 변화와 주변 사람이 같은 신호로 나타나는 한계를 확인한 뒤 현재 구조로 발전했습니다.

```text
규칙 기반 매트 경계 → MobileSAM 후보 분할 + 수동 보정
Motion 시작·종료 판정 → Motion 위치 탐색 + Vision 관절 판정
여러 Vision 관절 결합 → Motion 격자 기반 주 등반자 1명 선택·연속 추적
모델 우선 앱 시작 → 카메라 우선 진입 + 스트림 준비 후 모델 preload
무기한 매트 분석 대기 → 5초 제한 + 기본 경계 복구
```

Vision은 한 프레임에서 여러 observation을 반환하므로 사람마다 모델을 다시 실행하지 않습니다. build 13부터는 8열 Motion 격자로 최초 대상 위치를 선택하고, 이후에는 직전 관절 경계와 중심의 연속성을 사용해 같은 사람을 유지합니다. 전체 프로토타입과 릴리스별 변화는 [저장소 개발 이력](../../DEVELOPMENT_HISTORY.md)에 정리돼 있습니다.

## 결과 편집과 사진 보관함 검증

- 녹화 중 감지된 모든 원본 구간을 보존하고, 2초 미만의 짧은 구간만 인접 구간과의 간격이 3초 이내일 때 병합합니다.
- 최종 후보에는 앞뒤 3초 편집 여백을 적용합니다.
- 결과 화면에서 구간 확대, 0.1초 미세 조정, 중복 구간 방지, 같은 촬영 상태를 유지한 재촬영을 지원합니다. 확대 배율 슬라이더는 손잡이뿐 아니라 트랙 전체를 탭하거나 진동 없이 바로 드래그해 조절할 수 있습니다. 다시 촬영 확인창은 경고 본문을 13pt 기준의 동적 글꼴로 낮추고 버튼 크기는 유지합니다. 시작점 수정 후에는 새 시작점부터, 끝점 수정 후에는 새 끝점의 3초 전부터 자동 재생합니다.
- 마스크 포함 여부와 관계없이 선택 구간을 고화질로 다시 인코딩해 비디오 키프레임 사이에서 시작하더라도 첫 프레임부터 오디오와 맞춰 저장합니다.
- PhotoKit 저장 완료 시 생성된 `localIdentifier`를 보관하고, 같은 `PHAsset`을 다시 조회해 실제 `AVAsset`을 열 수 있을 때만 저장 성공으로 확정합니다.
- 검증된 구간은 임시 export 파일이 아니라 사진 보관함에서 다시 읽은 실제 asset으로 재생합니다.
- 여러 구간을 저장해도 구간별 검증 상태와 identifier를 각각 유지합니다.
- 결과 화면은 시스템 자동 잠금 시간을 따르며, 앱이 백그라운드로 이동하면 결과 영상과 사진 보관함 저장 영상 재생을 즉시 일시정지합니다.

## 저사양·장시간 촬영 자원 관리

- Ready 매트 분석은 탑홀드 선택과 별도의 비캐시 임베딩을 사용하고, 프롬프트마다 Core ML 임시 결과를 정리합니다.
- MobileSAM 모델과 임베딩은 빠른 재선택이 필요한 동안만 유지하고 녹화 진입·백그라운드·메모리 경고에서는 직렬 분석 큐를 통해 안전하게 해제합니다.
- 4K·60fps에서도 writer가 처리하지 못한 전체 해상도 `CMSampleBuffer`가 비동기 큐에 계속 쌓이지 않도록 캡처 delegate 큐에 역압력을 적용합니다.
- 앱이 비활성 상태이거나 결과·내보내기 화면에 있을 때 비동기 카메라·오디오 복구 작업이 캡처 세션을 다시 시작하지 않도록 생명주기를 제한합니다.
- 결과 화면에서 바로 다시 촬영할 때는 녹화 카운트다운과 MobileSAM 재로딩이 겹치지 않으며, 선택 화면에서 앱으로 복귀할 때만 카메라와 모델 준비를 다시 시작합니다.
- 백그라운드 자동 종료가 실제 영상 프레임 없이 끝난 경우에도 앱이 이미 활성 상태라면 카메라 프리뷰를 즉시 복구합니다.
- 시뮬레이터 빌드는 실제 iPhone의 peak RSS·Neural Engine 할당·프레임 드롭·발열을 측정하지 않으므로, 4K·60fps와 iPhone 12 mini급 기기는 별도 실기기 검증이 필요합니다.

## 빌드

1. `TopOut.xcodeproj`를 엽니다.
2. Development Team과 Bundle Identifier를 확인합니다.
3. `MobileSAM_Encoder.mlmodel`, `MobileSAM_Decoder.mlmodel`, `PrivacyInfo.xcprivacy`의 Target Membership을 확인합니다.
4. 카메라·마이크·사진 보관함 권한 문구를 확인합니다.
5. 실제 iPhone에서 Archive/실행 검증을 수행합니다.

```bash
xcodebuild -project TopOut.xcodeproj -scheme TopOut -configuration Debug \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```
