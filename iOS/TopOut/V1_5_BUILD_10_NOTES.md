# TopOut iOS v1.5 (build 10)

> 과거 릴리스 기록입니다. 현재 릴리스는 [v1.5 build 11](V1_5_BUILD_11_NOTES.md)이며 현재 동작은 [iOS README](README.md)를 기준으로 합니다.

## Camera audio recovery

- 전화 수신이나 다른 오디오 클라이언트 점유로 카메라 세션의 마이크 입력·출력이 제거된 뒤, 인터럽션 종료 또는 앱 활성화 시 오디오 캡처 그래프를 다시 연결합니다.
- 카메라 세션 전체를 다시 구성하지 않고 오디오 입력·출력만 복구해 기존 프리뷰 구도, 렌즈, 줌 좌표계를 유지합니다.
- 마이크 권한이나 오디오 세션 활성화가 불가능한 경우에는 기존 정책대로 영상 전용 녹화를 유지합니다.

## Portrait UI safety

- 세로 화면의 준비 완료, 설정, 줌, 녹화, 다시 촬영 컨트롤을 하단 안전 영역 안쪽 12pt에 배치했습니다.
- 홈 버튼 기기의 화면 잘림과 홈 인디케이터 영역의 제스처 충돌 위험을 줄였습니다.
- 가로 화면 배치와 촬영 영상 비율 계산은 변경하지 않았습니다.

## Review power lifecycle

- 촬영 화면을 벗어나 결과 화면에 진입하면 화면 켜짐 강제를 해제해 사용자의 시스템 자동 잠금 시간을 따릅니다.
- 앱이 백그라운드로 이동하면 결과 영상과 사진 보관함에서 연 저장 영상 재생을 즉시 일시정지합니다.
