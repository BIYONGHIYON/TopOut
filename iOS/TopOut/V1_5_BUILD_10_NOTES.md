# TopOut iOS v1.5 (build 10)

## iPhone startup compatibility

- MobileSAM 로딩이 앱 진입과 카메라 권한·프리뷰 준비를 막지 않도록 시작 순서를 분리했습니다.
- 실제 카메라 프레임이 안정된 뒤 모델을 백그라운드에서 준비하고, Core ML의 GPU 사용을 제외해 iPhone 12 mini 같은 메모리 제약 기기의 시작 안정성을 보강했습니다.
- 모델 준비가 실패하더라도 카메라 화면은 정상 진입하며 분석 시 재시도 또는 기존 기본 경계를 사용합니다.

## Frame-accurate clip export

- 마스크를 포함하지 않은 저장에서도 H.264 passthrough trim을 사용하지 않고 선택 구간을 고화질로 다시 인코딩합니다.
- 선택 시작점이 키프레임 사이에 있어도 첫 비디오 프레임부터 디코딩 가능한 새 구간으로 만들며, 저장 영상 초반은 오디오와 같은 시점에서 시작합니다.
- 저장 시간은 선택 구간 길이와 해상도·FPS에 따라 기존 passthrough 방식보다 늘어날 수 있습니다.

## Camera audio recovery

- 전화 수신이나 다른 오디오 클라이언트 점유로 카메라 세션의 마이크 입력·출력이 제거된 뒤, 인터럽션 종료 또는 앱 활성화 시 오디오 캡처 그래프를 다시 연결합니다.
- 카메라 세션 전체를 다시 구성하지 않고 오디오 입력·출력만 복구해 기존 프리뷰 구도, 렌즈, 줌 좌표계를 유지합니다.
- 마이크 권한이나 오디오 세션 활성화가 불가능한 경우에는 기존 정책대로 영상 전용 녹화를 유지합니다.

## Portrait UI safety

- 세로 화면의 준비 완료, 설정, 줌, 녹화, 다시 촬영 컨트롤을 하단 안전 영역 안쪽 12pt에 배치했습니다.
- 홈 버튼 기기의 화면 잘림과 홈 인디케이터 영역의 제스처 충돌 위험을 줄였습니다.
- 가로 화면 배치와 촬영 영상 비율 계산은 변경하지 않았습니다.

## Review power lifecycle

- 촬영 화면을 벗어나 결과 화면에 진입하면 화면 켜짐 강제를 해제해 사용자의 시스템 자동 잠금 시간을 따릅니다.
- 앱이 백그라운드로 이동하면 결과 영상과 사진 보관함에서 연 저장 영상 재생을 즉시 일시정지합니다.

## Release identity

- Marketing Version: `1.5`
- Current Project Version: `10`
- 전체 Swift 소스와 생성된 MobileSAM Core ML Swift 인터페이스 타입 검사를 통과했습니다.
