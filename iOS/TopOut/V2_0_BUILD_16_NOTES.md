# TopOut iOS v2.0 (build 16)

## 릴리스 기준

- Marketing Version: `2.0`
- Current Project Version: `16`

## 주요 변경 사항

- 영어, 한국어, 일본어, 중국어 간체, 중국어 번체, 프랑스어, 독일어, 스페인어, 포르투갈어 UI 지원
- 기본 `자동` 언어 선택과 설정 내 수동 언어 변경 추가
- iOS 선호 언어 순위에 따른 자동 선택과 지원하지 않는 언어의 영어 대체
- 카메라·녹화·결과 편집·설정·오류·접근성 문구 현지화
- 카메라·마이크·사진 보관함 권한 안내를 9개 언어의 `InfoPlist.strings`로 제공
- 언어 선택 즉시 설정·오픈소스 화면을 미리보기하고 `저장` 시에만 선택값을 확정
- 촬영·결과 버튼의 두 줄 단어 줄바꿈·가운데 정렬과 설정 스위치 폭 보존으로 긴 번역 레이아웃 보강
- 촬영·선택·결과 화면의 긴 상단 상태 문구를 최대 두 줄로 표시하고 가로모드 결과 컨트롤을 노치 안전 영역 안에 배치
- 언어 선택값은 앱 내부에만 저장하며 영상·분석 데이터 처리 방식은 변경하지 않음

## 릴리스 전 확인

- 각 언어에서 긴 설정·경고 문구의 줄바꿈과 가로·세로 UI 확인
- 자동·수동 언어 변경 후 카메라와 결과 화면 문구 갱신 확인
- App Store 업로드 전 Marketing Version `2.0`, Current Project Version `16` 확인
