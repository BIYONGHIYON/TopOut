# TopOut iOS v3.0 (build 23)

## 릴리스 기준

- Marketing Version: `3.0`
- Current Project Version: `23`
- Deployment Target: iOS `16.0` 유지

## 주요 변경 사항

### 녹화 시작과 매트 경계

- 녹화 시작 버튼을 녹화 정지 버튼과 같은 빨간 캡슐의 아이콘 전용 버튼으로 바꿈(흰 원 테두리 + 채운 원, VoiceOver `녹화 시작`)
- 자동 구간 탐지를 켜면 `준비 완료` → 매트 경계 측정 → 보정 화면(`다시 촬영` · 빨간 녹화 시작) 순서. 끄면 카메라 화면의 빨간 녹화 시작 버튼으로 바로 녹화
- 녹화 전에는 탑홀드를 고르지 않음. 보정 화면은 매트 경계만 다룸
- 경계 확정 1분 뒤 녹화를 자동으로 시작하던 기능 제거. 녹화는 빨간 녹화 시작 버튼으로만 시작
- 실시간 영상이 보이는 녹화 중에는 파란 점으로 경계선을 보정할 수 있고, 손을 떼면 진행 중인 탐지 상태를 유지한 채 바로 반영(`MotionDetector.updateMatLine`)
- 녹화 중 완등 판정은 항상 가장 높이 올라간 관절을 기준으로 함

### 탑홀드는 결과 화면에서 지정

- 영상을 멈추고 탑홀드를 탭하면 `AVAssetImageGenerator`로 그 시각의 프레임을 정확히 뽑아 MobileSAM 마스크를 만들고 `탑홀드 마스크`를 켬. 다시 탭하면 새로 만듦
- 두 손가락으로 영상과 마스크를 최대 5배까지 확대·이동한 뒤 탭할 수 있음(`ReviewVC+VideoZoom`). 확대 중 탭 위치는 원래 영상 좌표로 바꿔 계산
- `탑홀드 마스크` 버튼은 탑홀드 마스킹을 켠 녹화에만 표시. 마스크를 고르기 전 누르거나 처음 영상을 멈추면 탭 안내, 마스크가 체크된 상태에서는 확대해 다시 고를 수 있다는 안내 표시(도움말을 켰을 때)
- 마스크를 바꾸면 이전에 마스크를 넣어 저장한 결과는 지금 선택과 다른 것으로 봄
- 설정의 탑홀드 마스킹 설명을 `결과 화면에서 탑홀드를 탭해 영상에 표시`로 바꿈

### 탑홀드 외곽선 로직 교체

- 기존: 두 번째 마스크만 쓰고 탭 지점 색과 다른 픽셀을 HSV로 지운 뒤 가장 큰 덩어리를 볼록 껍질로 그림. 실패하면 주변 8점을 다시 디코딩. 흰·회색·두 색 홀드와 볼륨을 일부만 잡는 문제
- 새 로직(`HoldOutline.swift`, Android와 같은 규칙):
  - 탭 한 점의 다중 마스크 3개를 모두 후보로 보고, 저해상도 logit을 긴 변 512칸 격자로 이중선형 확대
  - 탭한 칸과 이어진 영역만 남기고 안쪽 구멍을 메움. 색상으로 자르지 않음
  - 화면의 25% 이상 펼쳐지거나 3.5% 이상을 덮는 후보는 벽·매트로 보고 제외
  - IoU + 0.5 × 안정도로 고르되, 점수 차이 0.03 이내에서 1.6배 이상 작은 후보가 있으면 탭한 홀드 하나만 잡도록 그쪽을 씀
  - 열림 2칸으로 잔가지 제거, 선 굵기 절반만큼 바깥으로 키운 뒤 닫힘 3칸으로 홈을 메워 테두리가 홀드를 가리지 않게 함
  - Douglas–Peucker(1칸)와 Chaikin 3회로 윤곽선을 다듬음
- 최소 원 지름을 절반으로 줄임: 짧은 변의 3.75%, 22px 이상, 6% 이하. 이보다 작은 홀드는 홀드 가운데에 최소 원, 홀드를 못 찾거나 5초를 넘기면 탭 위치에 최소 원
- `Correction.swift`, `PixelMap.swift`와 색상 필터·주변 재탐색 코드 삭제

### 결과 화면

- `다시 촬영` 버튼 제거. 1행 `5초 전 · 재생/정지 · 5초 후 · 선택 구간 저장`, 2행 `탑홀드 마스크 · 닫기`. 탑홀드 마스킹을 끈 녹화는 `닫기`가 2행 전체를 씀

### 메모리

- MobileSAM은 녹화를 시작할 때 내리고, 녹화가 끝나면 탑홀드 마스킹이 켜져 있을 때만 결과 화면용으로 다시 불러옴. 카메라 화면에서는 자동 구간 탐지를 쓸 때만 `준비 완료`용으로 미리 불러옴. 두 기능을 모두 끄면 불러오지 않음

### 기타

- iOS 17 이상에서 `AVCaptureDevice.RotationCoordinator`로 미리보기·녹화 회전각을 정해 iPhone Duo처럼 화면 형태가 바뀌는 기기에 대응
- 9개 언어 문구 정리: 결과 화면 탑홀드 탭 안내·마스크 지정·확대 안내 추가, 탑홀드 마스킹 설명 변경, 녹화 전 탑홀드 선택·자동 녹화 예고·탑홀드 추적·결과 화면 다시 촬영 경고 문구 삭제
- v3.0 개발 중 CoreMotion으로 거치를 감지해 경계선을 자동으로 재는 방식을 시도했다가 기기 테스트 뒤 준비 완료 방식으로 되돌림. 기록: [AUTO_MAT_PIPELINE_DESIGN.md](../../AUTO_MAT_PIPELINE_DESIGN.md)

## 릴리스 전 확인

- 자동 구간 탐지 ON: `준비 완료` → 경계선 → `다시 촬영`/빨간 녹화 시작. OFF: 빨간 녹화 시작으로 바로 녹화
- 보정 화면에서 줌·회전이 막히고, 다시 촬영하면 카메라 화면으로 돌아오는지
- 통화 없이·통화 중 각각 녹화 시작 직후 화면이 멈추지 않는지
- 실시간 영상을 켠 녹화 중 파란 점으로 고친 경계선이 이후 판정에 반영되는지
- 결과 화면에서 확대 → 탑홀드 탭 → 마스크가 홀드 가장자리 바깥에 그려지고 저장 영상에 반영되는지. 작은 홀드는 최소 원, 벽을 탭하면 최소 원
- 결과 화면 5초 전·5초 후·저장·탑홀드 마스크·닫기 동작
- 램 4GB 이하 iPhone(12 mini·SE 등)에서 4K 녹화와 결과 화면 첫 탑홀드 탭이 5초 안에 끝나는지
- App Store 업로드 전 Marketing Version `3.0`, Current Project Version `23` 확인
