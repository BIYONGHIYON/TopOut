# TopOut iOS v2.1 (build 18)

## 릴리스 기준

- Marketing Version: `2.1`
- Current Project Version: `18`

## 주요 변경 사항

- 벽과 매트 사이의 경계와 다음 조작을 9개 언어에서 더 구체적으로 안내
- 파란 점을 움직여 경계선을 보정하는 동작과 분석 후 수동 보정 가능 여부를 명확히 표시
- 결과 화면에서 자동 감지된 시작~완등 구간과 수동 시작점·종료점 선택 안내 개선
- 작은 화면에서도 촬영·선택·결과 상단 안내와 하단 Tip의 한 줄 자동 축소 유지

## 릴리스 전 확인

- 9개 언어의 준비·경계 보정·결과 화면 문구가 한 줄 안에서 잘리지 않는지 실기기 확인
- App Store 업로드 전 Marketing Version `2.1`, Current Project Version `18` 확인
